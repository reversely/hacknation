# Wren

Wren helps a small farm-tour business set up its website on a phone, in Kiswahili or English, and
handle visitors' bookings, questions and reviews with the owner's approval.

- **Demonstration:** [reversely-wren.hf.space](https://reversely-wren.hf.space/) walks through setting
  up the farm on the phone, the farm's website as a visitor sees it, and the owner approving what
  visitors asked for.
- **Chat evaluation:** [reversely-wren.hf.space/?view=evaluation](https://reversely-wren.hf.space/?view=evaluation)
  measures how often the website's chat hallucinates, before and after its guidelines, and covers the
  benchmarks behind the model choices and how the models handle privacy.

Every model runs open-weight on this Space's own GPU. A visitor without a Hugging Face account gets a
limited number of GPU runs a day; signing in raises it.
